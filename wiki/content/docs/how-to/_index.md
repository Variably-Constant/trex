Targeted recipes for specific tasks. Each page solves one problem with a command you can run.
If you are new to trex, read the [tutorial](../tutorial/) first.

- [Extract fields](extract-fields/) - pull typed values and key/value pairs out of text.
- [Rename or reshape matches](rename-matches/) - rewrite each match with a template.
- [Find tables with no delimiters](find-tables/) - detect ragged tabular structure by shape.
- [Segment text with no delimiters](segment-without-delimiters/) - cut where prediction breaks.
- [Match up to a symmetry](match-up-to-a-symmetry/) - fold case / shape and match the orbit.
- [Find values that break their history](find-outliers/) - thresholds read from the window,
  the column, or a key's earlier values, with no number in the pattern.
- [Choose a backend](choose-a-backend/) - CPU, GPU, streaming, dual-grain.
- [Use your own atoms from PowerShell](custom-atoms-in-powershell/) - declare, test, find,
  count and mask identifiers only your logs have.
